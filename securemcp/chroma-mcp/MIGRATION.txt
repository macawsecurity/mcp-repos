WHAT

- FastMCP import and constructor replaced by SecureMCP; name "chroma" -> "chroma-mcp".
- main(): mcp.run(transport='stdio') -> mcp.run().
- argparse description text: "FastMCP server for Chroma DB" -> "MCP server for Chroma DB".
- 22 tool parameters given a plain type.

- No tool body changed.

WHY
SecureMCP publishes six parameter types: str, int, float, bool, dict, list.
Other annotations (Optional[...], List[...], unions, models) are published as
"string", so each tool parameter gets a plain type. Only the annotation
changes; the original is kept in a "# was:" comment.

DIFFERENCES FROM UPSTREAM
- Argument checking. FastMCP validated and converted every argument before the
  tool ran; SecureMCP passes arguments as sent. Arguments are checked by the
  MAPL policy.
- Per-parameter schema detail (descriptions, item types, allowed values) is not
  published. The tool docstring carries it.

NOTES
- Results are returned exactly as chromadb gives them.
- --client-type, --host, --port and the other arguments choose the Chroma
  backend. They are not MCP transport settings and are unchanged.

REQUIREMENTS
- chromadb.
